Projektziel & Motivation

Das Ziel des Projekts war die Konzeption und Realisierung eines vollständig softwaregesteuerten, vierradgetriebenen (4WD) Modellfahrzeugs. Das Fahrzeug navigiert selbstständig durch Korridore, reagiert dynamisch auf Hindernisse und hält durch kontinuierliche Sensor-Messungen einen definierten Abstand zur linken Begrenzungswand (Wall-Following-Prinzip).

Das Projekt entstand im schulischen Rahmen der HTL Wien 10 (Klasse 6AAELI) und verdeutlicht praxisnah das Zusammenspiel von Mikrocontroller-Programmierung, nicht-blockierender Multitasking-Architektur, analoger Sensorsignal-Aufbereitung und präziser Motor-PWM-Ansteuerung.

Softwarearchitektur & Steuerungslogik

Der Quellcode in src/main.cpp verzichtet bewusst auf blockierende delay()-Aufrufe und setzt stattdessen auf einen deterministischen, zeitgesteuerten kooperativen Scheduler mit millis():

  • 25 Hz Kontrollschleife (40 ms Zyklus): Abtastung aller drei ADC-Kanäle, Ausführung der Sensor-Glättungsfilter und Aktualisierung der Fahrentscheidungen in der State Machine.
  • 10 Hz Telemetrieschleife (100 ms Zyklus): Ausgabe formatierter Echtzeit-Messwerte (F, L, R Entfernungen in cm, Motor-PWM-Werte) über die serielle Hardware-Schnittstelle (115200 Baud).
  • Asynchrones Taster-Polling: Permanente, prellfreie Abfrage der START- und STOP-Taster mit interner Pullup-Beschaltung.

Finite State Machine (FSM)

1. STOPP (Standby)

Startzustand nach Bootup oder bei Betätigung des STOP-Tasters. Motor-PWM auf 0 gesetzt. Das Fahrzeug wartet sicher auf den START-Befehl.

2. FORWARD (Fahrt)

Autonome Vorwärtsfahrt mit Wandverfolgung. Fällt der Frontabstand unter 30 cm, wechselt das System sofort in den Rückwärtsgang.

3. BACKWARD (Freifahren)

Gezieltes Rückwärts-Freifahren bei Blockaden. Die Hysterese schaltet erst bei einem Freiraum von ≥ 50 cm wieder auf Vorwärtsfahrt um (verhindert Schwingen).

Wandverfolgungs- & Differenzial-Lenkungsalgorithmus

Die Lenkung erfolgt über Skid-Steering (Differenzialantrieb): Durch unterschiedliche PWM-Werte für die linke und rechte Motorgruppe kurvt das Fahrzeug geschmeidig.

src/main.cpp — Wandfolge- und Ausweichlogik C++
// Soll-Abstand zur linken Wand: 35 cm const float TARGET_DIST = 35.0; const int BASE_SPEED = 180; // ~70% PWM Duty-Cycle // 1. Vorausschauende Kurvenerkennung (Wand vor dem Fahrzeug): if (ir_front < 70.0) { if (ir_right > ir_left + 10.0) { spd_right = spd_right * 0.3; // Scharfe Rechtskurve in den Freiraum } else if (ir_left > ir_right + 10.0) { spd_left = spd_left * 0.3; // Scharfe Linkskurve in den Freiraum } } // 2. Feine Wandabstands-Korrektur (Left-Wall-Following): else if (ir_left < 34.0) { spd_right = spd_right * 0.3; // Zu nah an linker Wand -> nach rechts steuern } else if (ir_left > 36.0) { spd_left = spd_left * 0.7; // Zu weit weg -> sanft nach links korrigieren }

Sensorkalibrierung & Signalaufbereitung

Optische Sharp-Infrarotsensoren liefern eine stark nichtlineare Kennlinie, bei der die Ausgangsspannung asymptotisch mit zunehmender Distanz abfällt. Zur exakten physikalischen Entfernungsbestimmung wurden die Sensoren empirisch kalibriert und über ein inverses Regressionsmodell in C++ linearisiert:

Distance [cm] = (M / (ADC_raw + D)) - K Empirisch in Excel ermittelte Kalibrierungskonstanten für minimale Restfehler über den gesamten Messbereich.

Zur Unterdrückung von analogem Rauschen und streifenden Reflexionen durchlaufen alle Messwerte einen gleitenden 2-Punkte-Tiefpassfilter vor der Auswertung in der State Machine:

Distance_filtered = (Distance_neu + Distance_vorherig) / 2.0 Effektive Glättung von Messspitzen bei minimaler Phasenverzögerung (Latenz < 40 ms).
